HSK Papers

Admin panel · Kelola JSON dan audio

Kelola paket dari satu tempat.

Katalog dibaca dari repositori GitHub yang nyata. Unggahan baru dilakukan langsung ke repositori tujuan atau Google Drive.

Catatan keamanan. Token GitHub dan kunci Drive hanya digunakan di tab ini, tidak ditanam di kode atau disimpan ke browser. Upload MP3 langsung membutuhkan Apps Script terbaru dan kunci upload yang disetel oleh pemilik Drive.

1. Koneksi dan sumber paket

Katalog publik dapat dibaca tanpa token. Untuk menyimpan JSON, hubungkan GitHub dengan fine-grained token yang hanya memiliki izin Contents: Read and write pada repo Beta dan Stable.

Token tidak disimpan setelah halaman ditutup atau dimuat ulang.
Memuat katalog GitHub…

2. Upload JSON soal

Validasi JSON, lalu simpan ke folder paket yang sesuai. Nama file mengikuti nilai code di dalam JSON.

Batas validasi: 2 MB per file.
Pilih folder dan file JSON untuk memulai.

3. Status paket dan audio

Daftar paket digabung dari Beta dan Stable. Versi Beta diprioritaskan jika kode tersedia di kedua repo. Status audio berasal dari indeks Google Drive.

Sedang membaca daftar paket…
Menunggu indeks Google Drive.

4. Upload atau hubungkan audio MP3

Pilih kode paket dari katalog atau masukkan kode baru. Pilihan satu file menggunakan kode tujuan; bila memilih beberapa file, setiap nama file harus berupa kode paket, misalnya H51001.mp3.

Batas 12 MB per file untuk upload lewat Apps Script. Untuk file lebih besar, unggah dahulu ke Drive lalu tempel tautannya di bawah.
Diperiksa oleh Apps Script, tidak disimpan pada repositori.
Konvensi file. Audio disimpan sebagai HSK Papers Audio/HSK N/HNxxxx.mp3. File dibuat dapat diakses oleh siapa pun yang memiliki tautan agar aplikasi dapat memutarnya; folder induk tidak dibuat publik.
Pilih kode paket dan file MP3 atau tautan Google Drive.

Repo target default adalah Beta. Upload ke Stable hanya terjadi jika tujuan Stable dipilih secara eksplisit. Tidak ada perubahan otomatis lintas repo.
